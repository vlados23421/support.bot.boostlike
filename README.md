# 🤖 BoostSocialLike Support Bot

Телеграм-бот поддержки для сервиса **BoostSocialLikeBot**. Помогает пользователям создавать заявки, узнавать курс монет и получать ответы на частые вопросы.

---

## 📱 О боте

**BoostSocialLike Support Bot** — это официальный бот поддержки, который позволяет:

- ✅ **Создавать заявки** в службу поддержки
- 💱 **Узнавать курс монет** (звёзды Telegram + криптовалюта)
- ❓ **Получать ответы** на частые вопросы
- 👨‍💻 **Связываться с оператором** в любое время

---

## 🚀 Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота и главное меню |
| `/admin` | Панель администратора (только для владельца) |
| `/close <id>` | Закрыть заявку по ID (только для владельца) |
| `/stats` | Статистика по заявкам и пользователям |

---

## 📦 Функционал

### 📝 Создание заявки
Пользователь описывает проблему, заявка сохраняется в базе данных и отправляется администратору.

### 💱 Курс монет
Информация о курсе обмена:
- **Звёзды Telegram** → монеты
- **Криптовалюта** → монеты

### ❓ Частые вопросы
Готовые ответы на популярные вопросы:
- Как пополнить баланс?
- Какие пакеты есть?
- Как создать задание?
- Почему задержка?

### 👨‍💻 Связь с оператором
Пользователь может быстро связаться с поддержкой через создание заявки.

## 🔐 Правила использования

### 1. Общие положения
- Бот предоставляется для пользователей сервиса **BoostSocialLikeBot**
- Использование бота означает согласие с настоящими правилами

### 2. Обязанности пользователя
- Предоставлять достоверную информацию при создании заявок
- Не использовать бота для спама или мошенничества
- Уважать время операторов поддержки

### 3. Ограничения
- Заявки обрабатываются в порядке очереди
- Время ответа: до 15 минут в рабочее время, до 2 часов ночью
- Администрация оставляет за собой право отказать в обслуживании

## 🔒 Политика конфиденциальности

### 1. Сбор данных
Бот собирает следующие данные:
- **Telegram ID** — для идентификации пользователя
- **Username** — для обратной связи
- **Текст заявки** — для обработки обращения

### 2. Использование данных
- Данные используются **только** для обработки заявок
- Информация не передаётся третьим лицам
- Данные хранятся в зашифрованной базе данных

### 3. Хранение данных
- Данные хранятся до полного решения проблемы
- Закрытые заявки удаляются через 30 дней
- Пользователь может запросить удаление своих данных

### 4. Защита данных
- Все данные передаются по зашифрованному каналу
- Доступ к базе данных имеет только администратор
- Регулярное резервное копирование

## 🚀 Установка и запуск

```bash
# Клонируем репозиторий
git clone https://github.com/ваш_никнейм/telegram-support-bot.git
cd telegram-support-bot

# Устанавливаем зависимости
pip install -r requirements.txt

# Создаём .env файл
echo "BOT_TOKEN=ваш_токен" > .env
echo "ADMIN_ID=ваш_telegram_id" >> .env

# Запускаем бота
python bot.py
